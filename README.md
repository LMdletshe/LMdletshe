## Featured Public Project

### Draft Lantern

AI-assisted competitive-gaming project used to explore how far AI can help turn a personal idea into a working product.

I built it around a League-inspired drafting problem because competitive games have real constraints: roles, counters, synergy, scaling, teamfight plans, and trade-offs. It started as a test of AI's ability to help make useful software, then became a personal tool for exploring draft decisions in a gaming context.

- Highlights: responsive UI, champion explorer, team synergy scoring, counter-pick guidance, saved teams, and shareable team links
